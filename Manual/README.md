# EIRENE code documentation

Documentation of the master version of [EIRENE](https://jugit.fz-juelich.de/eirene/eirene).

## LaTex source

The LaTex source of the EIRENE code documentation is [hosted on JuGit](https://jugit.fz-juelich.de/eirene/eirene-manual).

## Compilation

The easiest way to compile this document is running
```bash
latexmk -pdfdvi eirene.tex
```

## Contributing

EIRENE is an open source code and in the same manner the EIRENE code documentation is open source. We are very happy to accept contributions. Please refer to the [contributing guide](CONTRIBUTING.md) for more details.
